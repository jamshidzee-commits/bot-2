# online-shop-bot
Telegram-магазин: канал @Online_magazin12jam + бот @Online_magazin12jam_bot.
Админ присылает фото с подписью `Название | цена на Uzum | описание` → бот публикует карточку с ценой на 20% ниже и кнопкой «Заказать».
Покупатель оформляет заказ в боте, платит по реквизитам, админ подтверждает, бот присылает трек EMU Post.
Секреты: TELEGRAM_BOT_TOKEN, ADMIN_CHAT_ID, PAY_INFO (реквизиты). Переменные (необязательно): DELIVERY_FEE, DISCOUNT_PERCENT.
